# Feature Workflow
1. Planner writes requirement + acceptance criteria.
2. Architect inspects current code and documents architecture when boundaries/schema/API change.
3. Developer implements on a feature branch with tests.
4. Reviewer records blocking/non-blocking findings.
5. Developer resolves blocking findings.
6. QA executes acceptance/risk-based verification.
7. DevOps records deployment/migration/rollback readiness.
8. Human decides whether to merge/release.
